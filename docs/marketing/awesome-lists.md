# GitHub "awesome" lists

> **PL – instrukcja:** Każdy PR: forkuj repo → edytuj README w przeglądarce GitHuba (ikona ołówka) → dodaj JEDNĄ linijkę w odpowiednim miejscu → „Propose changes” → otwórz PR z opisem poniżej. Nie zmieniaj niczego innego (białe znaki, formatowanie). Jeden PR na listę. Bądź cierpliwy – opiekunowie przeglądają ręcznie, czasem tygodniami. Nie dopisuj funkcji, których nie ma (API/MCP/3D).
