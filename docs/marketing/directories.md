**URL:** https://www.sprite-lab.com

```
AI sprite generator & animator for indie game devs
```

(50 chars)

```
Turn a text prompt into game-ready 2D sprites, pixel art, tiles and icons, then animate them into sprite sheets and GIFs. Free to try, no card needed.
```
(150 chars)

**Long description (~150 words):**
```
SpriteLab is an AI game asset generator for indie game developers. Type a prompt and get game-ready 2D sprites as transparent PNGs, in 12 art styles. Pixel art is snapped to a real pixel grid with a limited palette, so it looks hand-made in your engine instead of blurry.

Any sprite can be animated: idle, walk, run, attack, jump, fly, turnaround, or a custom motion. SpriteLab also suggests motions that fit the sprite – a dog can wag its tail or bark, a car can drive or drift, a dragon can breathe fire. Choose 4, 6 or 9 key poses, or smooth mode with up to 18 frames using AI in-betweens, and export a sprite sheet, individual frames and a GIF.

You can also generate seamless floor and wall tiles, animated water and icons, keep everything organised in projects with automatic folder sorting, download a ZIP pack, and upscale pixel art for free. Commercial use is allowed.
```
